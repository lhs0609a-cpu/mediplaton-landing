제미나이는 한글 타이포를 자주 뭉갭니다. 두 가지 방식 중 선택하세요.

- **A안 (권장)**: 프롬프트 끝의 `[배경 전용]` 지시문을 붙여 **텍스트 없는 배경만** 생성 → 캔바/피그마에서 Pretendard로 카피 얹기. 글자 깨짐 0%, 카피 A/B 테스트도 자유.
- **B안 (빠름)**: 프롬프트 그대로 생성 후 한글 오타가 나면 재생성. 보통 3~5회 안에 정타 나옴.

**[배경 전용] 지시문** — 아래 문장을 프롬프트 맨 끝에 붙이세요:

```
IMPORTANT: Render NO text, NO letters, NO numbers, NO logos anywhere in the image.
Leave the specified area as clean negative space for text overlay added later.
```

```
Style: premium Korean fintech advertising, clean and trustworthy, high contrast,
```
